## Lessons / process

1. **WebFetch GitHub UI может lying про tags** — повторно ловлено и в
   llama.cpp b9246 (UI showed, registry 404), и в Phase O conflicts (UI
   marketplace plugin existed, я выдумал conflict).
2. **Verify через registry manifest API** не через page UI. Pattern:
   `curl -H "Authorization: Bearer $(curl -s "$registry/token?...")" $registry/v2/.../manifests/<tag>`.
3. **Не выдумывай conflicts** между двумя popular OSS systems — они
   обычно интегрируются. WebSearch "$A $B integration" + look for plugin
   marketplaces перед declaring conflict.
4. **Phase O.fix research delta:**
   - Dify VECTOR_STORE supports 25+ backends (per docs.dify.ai env reference)
   - RAGFlow DOC_ENGINE supports 5 (ES/infinity/oceanbase/opensearch/seekdb) —
     not milvus/qdrant/weaviate
   - Inside compose network — все container ports одинаковые (наши llama-*
     все `:8080`, host-side publish меняется)
5. **GSD methodology drift detected by user** ("ты вообще гсд не юзаешь?").
   Этот session journal + INDEX/STATE/ROADMAP/BACKLOG refresh — closure.
