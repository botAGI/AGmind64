# AGmind Agent Rules

## Правила Карпатого

- Доводи проект до production-ready состояния; не подменяй прод-готовность
  косметическим полированием.
- Перед правками читай существующие контракты, тесты и docs. Следуй локальным
  паттернам и не откатывай чужие изменения без прямой команды.
- Если факт может устареть или неизвестен, ресерчь и опирайся на
  первоисточники.
- Для изменения поведения используй TDD: failing test, минимальная правка,
  passing test.
- Fresh deploy считается готовым только при свежих проверках: tests, lint,
  types, pre-commit, Compose/Kubernetes render, env/secrets guardrails, no
  deploy-facing `latest`, rollback path.
- `README.md` и `README.ru.md` должны оставаться смысловыми зеркалами.
- Внутренние planning/agent артефакты не коммитить; локальные материалы должны
  быть в `.gitignore`.
- Коммиты делай аккуратными пачками после верификации; пушь только проверенное.
- Пользователю отвечай по-русски, с конкретными статусами, SHA, командами и
  остаточными рисками.
